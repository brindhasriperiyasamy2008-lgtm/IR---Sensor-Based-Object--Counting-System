# IR Sensor-Based Object Counting System

## 📌 Project Overview

The **IR Sensor-Based Object Counting System** is an embedded and IoT-based project designed to automatically detect and count objects passing through a specific point.

The system uses an **IR sensor** to detect objects, an **ESP32** to process the sensor signals, and an **LCD display** to show the real-time object count.

This project reduces the need for manual counting and provides a simple, low-cost solution for automatic object monitoring.

---

## 🎯 Objectives

- To automatically detect objects using an IR sensor.
- To count objects accurately in real time.
- To display the object count on an LCD.
- To use ESP32 for sensor data processing.
- To provide a foundation for IoT-based monitoring and automation.

---

## 🔧 Components Used

- **ESP32**
- **IR Sensor**
- **LCD Display**
- Connecting wires
- Power supply
- Breadboard
